# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work, and don't harass anyone.
This applies in issues, pull requests, discussions and anywhere else you represent the project.

To report unacceptable behavior, contact the maintainer privately through the email on
[their GitHub profile](https://github.com/OrenSegal) instead of a public issue. Reports are
handled confidentially. The maintainer may remove comments, close threads or block participants
who don't follow this code.
